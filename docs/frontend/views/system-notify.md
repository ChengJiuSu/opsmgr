# 消息通知（`views/system/Notify.vue`）

**路由：** `/system/notify`　**权限：** `meta.perm = ['system', 'write']`
**菜单：** 系统管理 → 消息通知（「飞书接入」之后）
**接口：** `src/api/notify.js` → `/api/notify/`（见 [notify_mgr](../../backend/modules/notify_mgr.md)）

三个页签：

## 订阅规则

- 列表：规则名称、订阅事件（成功绿 / 失败红）、三维度（空显示「不限」）、发送方式 + 目标、
  @ 发起人、启用开关（行内切换，失败回滚）、测试 / 编辑 / 删除。
- 表单：事件多选按后端注册的分组渲染（`/api/notify/events/`，新增规则默认全选
  `default=true` 的事件）；发送方式默认「群机器人」，切到「应用机器人」时选「飞书接入」
  登记的会话（停用的置灰）；项目组 / 渠道 / 环境多选，留空不限。
- 打开弹窗时现拉会话与机器人下拉，刚新增的机器人不用刷新页面。

## 群机器人

- 列表：名称、打码 token、签名是否配置、被几条规则引用、状态、备注、测试 / 编辑 / 删除。
- 表单：Webhook 接受整条地址或 token；token 与签名密钥都只写，编辑时留空 = 不修改；
  已配签名时多一个「清除签名密钥」勾选。
- 删除确认文案带出将连带删除的规则数。

## 发送记录

- 按关键词 / 事件 / 状态筛选；状态着色：已发送 success、发送失败 danger、已跳过 info。
- 「说明」列显示失败原因或跳过原因（目标停用、该会话已有实时卡片）。

## 相关改动

- 任务流表单（`task/Executions.vue`）：「消息通知」开关，默认开；列表里关闭的任务名后带
  灰色「通知关」标签。该开关与「执行时默认全选范围主机」「允许从飞书发起执行」
  同放在「执行选项」区，每项一行（左控件、右说明）。
- 飞书接入（`system/Feishu.vue`）：会话弹窗去掉播报配置，列表改为「订阅规则 N 条」。
- `utils/request.js` 的 sudo 动作文案加了群机器人 / 订阅规则两条。
