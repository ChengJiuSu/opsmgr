# API 凭证（`/system/api-credentials`）

**组件：** `src/views/system/ApiCredentials.vue`
**API：** `src/api/apikeys.js`
**权限：** 仅管理员（路由 `meta.staff = true`）；写操作后端要求 sudo 二次验证，
由 `utils/request` 拦截器统一弹框并重放，页面无需处理。

内部脚本 / Webhook 免登录调用平台接口的凭证管理页。后端语义见
`docs/backend/modules/auth.md` 的「API 凭证」章节。

---

## 页面结构

- toolbar：说明文案（校验链顺序）+ 刷新 + 新增凭证
- 表格（列表不分页，后端返回 DRF 原生数组）：名称 / 凭证标识 / 作用域 / 来源 IP /
  签名 / 限速 / 最近使用 / 状态 / 备注 / 操作
- 弹窗：新增·编辑表单（分「来源限制」「Webhook 签名」「其他」三段）
- 弹窗：一次性 Key 展示（含 curl 调用示例 + 复制按钮）

---

## 交互要点

| 点 | 行为 |
|----|------|
| Key 明文 | 只在创建 / 轮换的响应里出现一次，弹窗 `close-on-click-modal=false`，文案说明「关闭后不再展示」|
| IP 白名单 | 未勾「不限制 IP」时前端也做必填校验（与后端同一条规则），提示语指向勾选框，避免用户以为是 bug |
| 不限制 IP | 勾选后即时显示红色告警文案，白名单输入框隐藏 |
| 签名方式 | 切换时自动填入常见请求头默认值（`X-Hub-Signature-256` / `X-Gitlab-Token`）与前缀 `sha256=`；切回「不验签」清空相关字段 |
| 签名密钥 | 不回显。编辑时占位提示「已设置，留空保持不变」，提交前删除空值字段 |
| 轮换 Key | 二次确认，文案说明旧 Key 立即失效、调用方会开始报 401 |
| 停用 vs 删除 | 停用文案强调「可随时恢复，泄露时优先用它」；删除文案强调不可恢复并引导改用停用 |
| 状态标签 | 已过期 danger / 启用 success / 停用 info（`expired` 由后端计算返回）|

---

## 状态色约定

| 场景 | 颜色 |
|------|------|
| 不限制来源 IP | `danger`（红，提示这是危险配置）|
| 已配置签名 | `success` |
| 不验签 / 停用 | `info` |
| 已过期 | `danger` |
